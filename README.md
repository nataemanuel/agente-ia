# 🎨 Atualizações Recentes (Melhorias de Design & UX)

Hoje o projeto passou por uma grande reformulação visual e de usabilidade (UX), focando principalmente na experiência em dispositivos móveis e refinamento de detalhes:

* **📱 Menu Lateral Responsivo (Mobile):** Corrigido o problema onde as opções de histórico e novas conversas sumiam no celular. Agora, a `sidebar` se transforma em um menu lateral deslizante (estilo gaveta) que aparece ao tocar no botão de menu `☰`.
* **🟢 Feedback Visual do Status:** O indicador de `Conversa Ativa` recebeu uma nova cor estilizada (Verde vibrante), facilitando para o usuário identificar rapidamente o status atual da sessão.
* **✨ Camada de Fundo (Overlay):** Adicionado um efeito de fundo escurecido quando o menu mobile está aberto, melhorando o contraste e permitindo fechar o menu apenas clicando fora dele.
